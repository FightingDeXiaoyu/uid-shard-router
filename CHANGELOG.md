# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-04-14

### Added

- Initial zero-dependency Java routing library
- `UidShardRouter` core API for deterministic uid-based shard routing
- CLI entry point for support and scripting workflows
- Self-test suite runnable with plain `javac` and `java`
- MIT license, contribution guide, roadmap, and CI workflow
